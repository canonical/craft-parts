fpc plugin
==========

The fpc plugin builds programs with the `Free Pascal`_ compiler. It compiles each
listed program together with the units it uses, and installs the resulting executables
in ``$CRAFT_PART_INSTALL/bin``. Units provided by other parts can be shared with the
:ref:`fpc-use plugin <craft_parts_fpc_use_plugin>`.


Keys
----

This plugin provides the following unique keys.


fpc-programs
~~~~~~~~~~~~

**Type:** list of strings

**Required**

The source files of the programs to compile, relative to the source directory. Each
entry produces one executable, named after its source file.


fpc-unit-paths
~~~~~~~~~~~~~~

**Type:** list of strings

Directories to search for units, relative to the source directory. Each entry is
passed to the compiler with ``-Fu``. The compiler always searches the directory of
the program being compiled. An entry ending in ``/*`` adds every subdirectory of that
directory instead of the directory itself.


fpc-include-paths
~~~~~~~~~~~~~~~~~

**Type:** list of strings

Directories to search for include files, relative to the source directory. Each entry
is passed to the compiler with ``-Fi``. An entry ending in ``/*`` adds every
subdirectory of that directory instead of the directory itself.


fpc-parameters
~~~~~~~~~~~~~~

**Type:** list of strings

Additional parameters to pass to the compiler, such as ``-O2`` or ``-dDEBUG``. They
are placed after the parameters generated by the plugin, so they can override them.


Environment variables
---------------------

This plugin sets no environment variables.


.. _fpc-details-begin:

Dependencies
------------

The fpc plugin needs the ``fpc`` executable to build programs but does not provision
it by itself, to allow flexibility in the choice of compiler version.

Common means of providing ``fpc`` are:

* The ``fpc`` Ubuntu package, declared as a ``build-package``. The ``fp-compiler``
  package provides the compiler and the run-time library only.

Another alternative is to define another part with the name ``fpc-deps``, and declare
that the part using the ``fpc`` plugin comes after the ``fpc-deps`` part through the
``after`` key. In this case, the plugin will assume that this new part will stage the
``fpc`` executable to be used in the build step.

.. _fpc-details-end:


How it works
------------

During the build step the plugin performs the following actions:

#. Create the directory for compiled units, ``.parts/units`` in the build directory,
   and the ``bin`` directory in the install directory.
#. Call ``fpc`` once for each entry in ``fpc-programs``, passing the entries in
   ``fpc-unit-paths`` and ``fpc-include-paths``, the search paths exported by the
   :ref:`fpc-use <craft_parts_fpc_use_plugin>` parts listed in ``after``, the two
   directories above through ``-FU`` and ``-FE``, and finally the entries in
   ``fpc-parameters``.


Example
-------

The following snippet declares a part using the ``fpc`` plugin. It builds two programs
from the ``src`` directory, resolving the units they use from the ``units`` directory
and their include files from the ``include`` directory, with optimizations enabled:

.. code-block:: yaml

    parts:
      hello:
        plugin: fpc
        source: .
        build-packages:
          - fpc
        fpc-programs:
          - src/hello.pas
          - src/goodbye.pas
        fpc-unit-paths:
          - units
        fpc-include-paths:
          - include
        fpc-parameters:
          - -O2

## How to Re-run or Query

Use the included shell script `./find_s390x_failures.sh`:

```bash
# Show help
./find_s390x_failures.sh --help

# Query table of recent runs
./find_s390x_failures.sh --limit 50 --format table

# Filter only for java plugin failures
./find_s390x_failures.sh --filter-job java --format table

# Export full list to JSON or TSV
./find_s390x_failures.sh --format json -o s390x_failures.json
./find_s390x_failures.sh --format tsv -o s390x_failures.tsv
```
